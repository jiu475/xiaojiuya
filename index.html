使用说明书

从这里开始，了解收藏、管理、备份与恢复。

先记住两件事

① 资料默认保存在当前浏览器，不会自动上传云端。② 更换浏览器、清除网站数据或更换设备前，请先导出完整 JSON 备份。

一、快速认识首页

「总览」查看 API 数量、最近添加记录和外观设置。左侧目录切换各个功能模块；手机上可点「目录」打开导航。右下角「＋」可以快速新增 API、网址、角色卡、素材或小剧场。

二、API 管理
  1. 进入「添加 API」，填写名称、Base URL 和服务商提供的密钥；分类、模型、标签和备注按需填写。
  2. 保存后可在 API 列表查看、编辑、复制地址或密钥，并使用连接测试/模型拉取（具体取决于服务商接口是否兼容）。
  3. 密钥属于敏感信息，避免截图分享；不要把带密钥的备份发送给他人。
  4. 遇到跨域/CORS 错误时，通常是服务商或浏览器限制，不一定代表密钥错误。
三、收藏网址

在「收藏网址」添加名称、网址、可选分类和备注；可以整理常用控制台、SillyTavern 地址、文档和签到页。备注不要填写密码。点击网址前确认域名可信。

四、角色卡收藏馆

可导入支持的 SillyTavern PNG 角色卡并解析其中的角色 JSON。导入后检查角色名、简介和原始数据，再保存。不同来源或版本的 PNG 元数据可能不同；若解析失败，请保留原始 PNG 并尝试酒馆导出的 JSON。应用通常保存解析数据和预览图，不应把它当作原始 PNG 的唯一备份。

五、世界书、素材与酒馆预设

「世界书与素材库」顶部标签或左侧子目录可分别查看世界书、酒馆预设、剧情片段和酒馆美化主题。剧情片段可填写关联角色，小剧场也可关联角色并按角色筛选。酒馆预设可在「世界书与素材库 → 酒馆预设」目录顶部导入 JSON；CSS 文件可在独立目录保存和查看原文；本版本不再模拟真实酒馆运行环境。不同酒馆版本与扩展格式可能存在差异，请保留原文件并核对导入结果。

六、收藏小剧场

可以保存文字内容或 HTML 小剧场。HTML 预览可能运行脚本；只运行你信任的代码，不要把含有未知脚本的文件当作安全内容。需要修改时先备份原文。

七、全局搜索

使用顶部搜索框查找 API、网址、角色卡、素材和小剧场的相关文本。搜索不会用于显示 API 密钥；如搜索结果不全，请进入对应模块检查分类筛选。

八、备份与恢复（非常重要）
  1. 定期进入「备份与恢复」，点击完整 JSON 导出，并把文件保存到手机文件管理器或可靠的云盘。
  2. 导入前先导出当前版本，作为恢复点。
  3. 合并模式会按记录 ID 合并；全量替换会替换现有模块数据，操作前务必确认。
  4. 备份可能包含 API 密钥、私人角色卡和个人资料，请妥善保管。
  5. 导入后检查各模块记录数量和重要内容是否齐全。
九、主题、壁纸与手机使用

首页「外观与壁纸」可切换主题和设置壁纸。壁纸按原始文件保存，不会被压缩或缩放。建议使用最新版 Chrome 等现代浏览器；磨砂玻璃效果受浏览器支持影响。若安装成 PWA，也请保持固定网址并定期备份。

十、常见问题排查
  • 刷新后资料不见：确认网址和浏览器没有改变；检查是否清除了网站数据；尝试从备份导入。
  • 保存失败：可能是浏览器存储空间不足；先导出备份，再减少过大的图片或长文本。
  • 导入失败：确认文件类型正确、JSON 完整，且文件没有损坏；酒馆预设使用专用入口。
  • 模型拉取失败：检查 Base URL、密钥、服务商接口兼容性和跨域限制。
  • 换设备使用：本地数据不会自动迁移；需手动导出并在新设备导入，或另行搭建云端同步。
隐私与安全声明

当前版本是本地浏览器存储工具，不提供服务器端账号或自动云同步。任何网页本地存储都可能因浏览器清理、设备故障或用户操作而丢失，因此完整 JSON 备份仍然必不可少。
